## Reproducing everything

```bash
pip install numpy scipy matplotlib pandas        # numpy 1.21 … 2.x
cd research/paper/analysis
python run_estimators.py      # DS-2: 45 sweeps × 7 estimators, as-is and firmware-corrected → results/sweeps_*.csv      (~40 s)
python -c "import run_glucose, data; d, m = data.glucose_0529(); [run_glucose.estimators(d, m, v, v == 'fwfix') for v in ('asis', 'fwfix')]"   # DS-3 → results/glucose_sweeps_*.csv (~1 min)
python run_v2.py              # shifts, KG-1/2/3, bias, φ, glucose, datalogs → results/v2/<variant>/              (~5 s)
python run_bias_theory.py     # closed forms vs model curves, OSL delays → results/bias_theory.md
python run_forward_model.py   # synthetic truth through the front end → results/forward_model.md
python make_figures_v2.py     # figures → ../figures_v2 (+ si/), provenance → results/v2/figure_provenance_v2.md
python make_si.py             # SI tables → ../manuscript/supporting_information.md
python md2tex.py              # LaTeX → ../arxiv/main.tex, si.tex, figures/, references.bib
```

`qcmchain.py` is an independent re-implementation of the chain written from the equations (it shares only the smoothing definition with the instrument); it reproduces `software/tests/data/psl_expected_2026-09-11.json` to all printed digits.

## Main findings in one paragraph (v0.2)

On overtones 3–9 of two instruments and two crystals, the maximum of the reconstructed conductance overshoots the Kanazawa–Gordon frequency shift by 20–36 % while its half-height width is within 7 % of the bandwidth shift (KG-1 ratio ΔΓ/(−Δf) = 0.71–0.85); the phase-shifted Lorentzian brings the frequency shift to −1…+8 % (board 1920, water and isopropanol) and +6…+13 % (second instrument, water), leaves the bandwidth within 5–9 %, and moves the ratio to 0.86–1.02. The excess of the maximum is the closed-form bias Γ·tan(φ/2) of a rotated resonance, verified on 120 sweeps to 0.12 Γ. KG-2 (√n scaling) holds with the fit on both instruments (log–log slopes −0.49 to −0.58); KG-3 reproduces the tabulated √(ρη) ratio of isopropanol to water to 1–4 % and resolves glucose steps of 2.5 % w/v (4 % in √(ρη)) at ≥14 replica standard deviations (noise-equivalent 0.04–0.12 % in relative √(ρη)). The rotation angle is an instrument property to first order (replica-stable to 0.3°, independent of the liquid and of its concentration to 2° on n = 3–9, −8° → −30° from 5 to 45 MHz) but differs between air and liquid by 3–8° at the fundamental and by 4–5° on one overtone, is non-monotonic in n on one board, and differs between boards by up to 5°. The repository's "8 %" claim holds for the frequency on board 1920 and not on the second instrument (10–13 %), and is not an improvement for the bandwidth. The fundamental follows the theory on one crystal and not on the other.
