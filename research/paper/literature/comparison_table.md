# Literature comparison tables

Revised 2026-10-08 (v2). Conventions: "n/r" = not reported in the sources read; "(I)" = inferred from an abstract, snippet or secondary source — check the full text; "(V)" = read in the paper, the code or the vendor page; "(U)" = unverified. Reference numbers refer to the list in `literature_review.md`. "KG" = Kanazawa–Gordon.

## Table 1 — Compact comparison for the main text

Reading of Table 1: rows 2 and 3 already combine phase measurement, complex-admittance reconstruction and a fit; rows 4–7 share hardware blocks with row 8 but none of them reconstructs G + jB from a scalar gain/phase detector, fits a Lorentzian to it, or reports a numeric multi-overtone KG comparison. Row 2 is the only one with a multi-overtone √n test in liquid, on bench or lab-built hardware.
